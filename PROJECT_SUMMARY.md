## 🔧 Customization Guide

### Update Company Name
Edit `Navigation.jsx` line 46:
```javascript
<motion.a href="#" className="text-2xl font-bold gradient-text">
  Your Company Name
</motion.a>
```

### Update Colors
Edit `tailwind.config.js`:
```javascript
colors: {
  primary: "#your-color",
  secondary: "#your-color",
  accent: "#your-color",
}
```

### Update Services
Edit `Services.jsx` array with your 8 services

### Update Team Members
Edit `Team.jsx` array with your team info

### Update Portfolio
Edit `Portfolio.jsx` array with your projects

### Update Testimonials
Edit `Testimonials.jsx` array with client reviews
